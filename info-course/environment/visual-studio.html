環境と成果

Visual Studio

プログラムを書き、実行し、誤りを確かめる開発環境です。

要点 01

2017年にVisual Studioを導入

西館マルチメディア教室の更新に合わせ、プログラミング用ソフトとしてVisual Studioを導入しました。

要点 02

コードから実行へ

入力したプログラムを実行し、結果やエラーを確認しながら修正する一連の作業を支えます。

要点 03

ゲーム体験にも接続

C++を使ったゲームプログラミング体験など、コードと画面上の動きを結ぶ学びとも相性のよい環境です。

学習工程

Visual Studioで進める4段階

  1. 01条件を読む

    「Visual Studio」では、入力・処理・出力へ分け、必要な値と結果を決めます。

  2. 02手順を組む

    「Visual Studio」では、図や短い言葉で処理順を整えてからコードへ移します。

  3. 03実行する

    「Visual Studio」では、小さな単位で動かし、どこまで正しいかを確かめます。

  4. 04原因を直す

    「Visual Studio」では、値、条件、処理順、エラー表示から違いを探します。

Visual Studioの学び方

コードを書く前に

「Visual Studio」では、課題の条件を入力・処理・出力へ分けます。

「Visual Studio」では、処理の順序を図や短い言葉で整理してから、プログラムへ置き換えます。

実行して、原因を探す

「Visual Studio」は、入力して終わる授業ではありません。

「Visual Studio」では、実行結果が予想と違うときは、値、条件、処理順、エラー表示を一つずつ確かめます。

つまずきを残さない

「Visual Studio」では、どこまで正しく動いたかを切り分けてから質問します。

「Visual Studio」では、1・2年次の実習は原則2名の教員が担当し、操作と考え方の両方を支えます。

成果は動作と説明

「Visual Studio」では、提出時は、指定した条件で正しく動くかを確かめます。

「Visual Studio」では、コードだけでなく、工夫した処理と修正した理由も説明できる形で残します。

次の専門学習へ

「Visual Studio」で使った分解と検証は、「自分のPCでも使える制作環境」でも土台になります。

「Visual Studio」では、言語や機器が変わっても、条件から手順を組み立てる力は共通です。

体験入学で見るところ

「Visual Studio」では、完成例だけでなく、エラーが出たときにどう戻るかも見てください。

「Visual Studio」では、初めての人へどのように説明し、どこで教員へ質問できるかを確かめられます。
