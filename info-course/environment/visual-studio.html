情報コースTOP ／ 学習環境 ／ Visual Studio

ENVIRONMENT

Visual Studio

プログラムを書き、実行し、誤りを確かめる開発環境です。

POINT 01

2017年に導入を確認

西館マルチメディア教室の更新時、プログラミング用ソフトとしてVisual Studioが導入されました。

POINT 02

コードから実行へ

入力したプログラムを実行し、結果やエラーを確認しながら修正する一連の作業を支えます。

POINT 03

ゲーム体験にも接続

C++を使ったゲームプログラミング体験など、コードと画面上の動きを結ぶ学びとも相性のよい環境です。
